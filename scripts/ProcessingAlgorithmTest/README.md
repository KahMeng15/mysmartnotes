# Processing Algorithm Test

Simple text extraction and processing script.

## Quick Start

1. Place your file as `INPUT.txt`, `INPUT.pdf`, `INPUT.docx`, `INPUT.pptx`, or `INPUT.doc`
2. Run: `python run.py`
3. Check `output/` folder

## Output Files

- **extracted_text.txt** - Raw unprocessed text
- **processed_output.html** - Processed text with HTML tags (p, h1, h2, h3)

## Supported Formats

- PDF, TXT, DOCX, DOC, PPTX
